# WSR slide preview on Linux

See **[WSR_SLIDE_PREVIEW.md](./WSR_SLIDE_PREVIEW.md)** for full documentation.

**Summary:** LibreOffice previews are often misaligned and use wrong fonts. For production on Ubuntu/GCP, use **`PPT_RENDER_BACKEND=remote`** with a Windows machine running `scripts/ppt_render_server.py` (real PowerPoint COM).
